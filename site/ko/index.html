어디서든 돌아갈 만큼 작은 에이전트

C 코드 1,400줄 · 90 KB · RAM 약 2 MB · 의존성 2개

skill.md + llm + shell + loop

할 일을 마크다운 파일에 적으면, SubZeroClaw가 그 내용을 시스템 프롬프트에 넣고 모델을 호출한 뒤 모델이 요청한 셸 명령어를 실행합니다. 일이 끝날 때까지 이 과정을 되풀이합니다.

도구는 셸 하나뿐입니다. 그래서 머신에 이미 설치된 것(git, curl, jq, ffmpeg)은 연동을 따로 만들 필요 없이 모두 바로 쓸 수 있습니다.

모델 선택, 프롬프트 캐싱, 컨텍스트 압축은 unhardcoded 라우터가 맡습니다. 그래서 루프는 작게 유지되고, 요약하느라 멈추는 일도 없습니다.

$ git clone https://github.com/genlayerlabs/subzeroclaw
$ cd subzeroclaw && make
$ mkdir -p ~/.subzeroclaw/skills
$ cat > ~/.subzeroclaw/config <<'EOF'
api_key       = "llmr_…"
endpoint      = "https://YOUR-ROUTER/v1/chat/completions"
request_extra = {"model":"policy:auto","policy_ir":[…]}
EOF
$ ./subzeroclaw "check disk usage and clean tmp if over 80%"
# 모든 호출과 명령어는 ~/.subzeroclaw/logs/에 기록됩니다

설정 레퍼런스, 스킬, 선택 기능인 결정 컨트롤러는 README에서 확인하세요.

모델과 셸 사이를 가로막는 것은 없습니다

샌드박스도, 실행 전 확인도, 허용 목록도 없습니다. 모델이 실행하기로 한 것은 무엇이든 그대로 실행됩니다. rm -rf /도 예외가 아닙니다. 통째로 날아가도 괜찮은 머신이나 컨테이너에서 돌리세요.

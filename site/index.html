SubZeroClaw
v0.1 · MIT Docs GitHub ↗

an agent small enough to run anywhere

1,400 lines of C · 90 KB · ~2 MB RAM · 2 deps

skill.md + llm + shell + loop

Describe the job in a markdown file. SubZeroClaw puts it in the system prompt, calls the model, runs the shell command the model asks for, and repeats until the job is done.

The shell is the only tool, so everything already installed on the machine (git, curl, jq, ffmpeg) is an integration you don't have to write.

Model choice, prompt caching and context compaction live in the unhardcoded router, so the loop stays small and never pauses to summarize.

$ git clone https://github.com/genlayerlabs/subzeroclaw
$ cd subzeroclaw && make
$ mkdir -p ~/.subzeroclaw/skills
$ cat > ~/.subzeroclaw/config <<'EOF'
api_key       = "llmr_…"
endpoint      = "https://YOUR-ROUTER/v1/chat/completions"
request_extra = {"model":"policy:auto","policy_ir":[…]}
EOF
$ ./subzeroclaw "check disk usage and clean tmp if over 80%"
# every call and command is logged to ~/.subzeroclaw/logs/

Config reference, skills and the optional decision controller are in the README.

Nothing stands between the model and your shell

No sandbox, no confirmation prompts, no allowlist. Whatever the model decides to run, runs, rm -rf / included. Give it a machine or container you can afford to lose.
